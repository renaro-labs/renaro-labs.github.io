01 / thesis

constraint is part of the research question.

renaro is designed around a practical premise: compute, memory, latency, and deployment constraints are not just engineering annoyances. they can shape better research questions.

01

efficient by default

prefer small models, frozen specialists, quantized serving, and sparse intervention over brute-force scale.

↗ resource-aware design
02

failure-aware

study what a system is missing at the moment it fails, not only what it predicts from the initial prompt.

↗ state-conditioned reasoning
03

evidence over theater

benchmarks, ablations, matched budgets, telemetry, and reproducible configs matter more than a flashy demo.

↗ measurable claims
02 / current research program

fasa

failure-aware sparse capability acquisition asks whether a small language model can detect its current capability gap, acquire only the missing capability from a specialist, and continue reasoning with a verifiable intervention.

01

keep the small model primary

the main slm is not replaced. it remains the local reasoner; specialists exist only as capability providers when the controller predicts that intervention is worth the cost.

02

route from the reasoning state

the controller can consider the task, partial reasoning, recent verifier signals, self-confidence, and lightweight failure patterns instead of looking only at the initial prompt.

03

diagnose the missing capability

a lightweight detector maps the current state to a capability-gap distribution. the inference-time representation can stay compact and need not produce a verbose diagnosis.

04

choose expert or stop

the proposed decision compares expected counterfactual improvement with acquisition cost and includes a null action: continue without consulting anyone.

05

math specialist

qwen2.5-math-7b-instruct supplies targeted symbolic manipulation, derivations, and mathematical reasoning artifacts.

06

code specialist

qwen2.5-coder-7b-instruct supplies focused implementation reasoning, bug diagnoses, patches, and test insights.

07

biomedical specialist

biomistral-7b is intended for specialized biomedical terminology, scientific knowledge, and evidence-style support.

08

legal specialist

saul-7b-instruct-v1 is intended for legal terminology, rule-oriented reasoning, and issue/application style analysis.

09

generalist fallback

qwen3-8b provides broad reasoning capability when the specialized pool does not clearly match the failure state.

10

exchange capability, not whole answers

the interface is deliberately typed: a specialist returns a compact derivation, patch, fact, rule, or reasoning strategy rather than regenerating the full task solution.

11

verify before committing

the verifier gate checks whether the artifact actually helps. deterministic checks are preferred when available, with rejection or retry when the evidence is not trustworthy.

12

return control to the slm

accepted evidence goes back into the primary model's reasoning process. sparse consultation keeps the system centered on local inference.

03 / execution

10 weeks from baseline to paper.

the current roadmap deliberately front-loads baselines and infrastructure, then freezes the method before the final experiment cycle.

W1–2 / foundation

baseline first. no learning yet.

freeze the experimental specification, verify local inference for the main model and advisor pool, define the evaluation harness, and establish performance / latency / memory baselines before training a controller.

04 / what we measure

better means a better frontier.

renaro's proposal does not treat accuracy as the only scoreboard. quality has to be read together with the resources needed to obtain it.

task qualityaccuracy / utilitydoes the task actually improve?
consultation sparsityexpert calls / taskhow often does the system ask for help?
transfer costtokens / latencyhow much communication does the repair need?
deployment costmemory / energycan it remain practical on constrained hardware?
